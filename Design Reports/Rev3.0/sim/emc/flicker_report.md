# Flicker assessment: triac-switched 1 kW heater vs IEC 61000-3-3

Filament dryer, 230 V / 50 Hz, resistive heater 52.9 ohm switched by a triac at full mains cycles. All scripts, JSON results and plots are in this folder; every number below is regenerated by `validate_flickermeter.py`, `flicker_sigma_delta.py`, `flicker_alternatives.py`, `make_report.py`.

## 1. Method

| block | implementation (`flickermeter.py`) |
|---|---|
| input | terminal voltage sampled at 4 kHz (40 samples per half cycle) |
| 1 adaptor | x / sqrt(mean-square), mean square from a first-order LP, tau 27.3 s, initialised at the first cycle |
| 2 demodulator | squaring |
| 3 filters | 6th-order Butterworth LP 35 Hz at 4 kHz; decimation 4 -> 1 kHz; Butterworth HP 0.05 Hz (1st order per IEC 61000-4-15 text; 6th order as in the brief also run, see validation); weighting filter k = 1.74802, lambda = 2 pi 4.05981, w1..w4 = 2 pi (9.15494, 2.27979, 1.22535, 21.9), bilinear transform at 1 kHz |
| 4 | squaring + first-order LP tau 300 ms; gain 319140 set so that 8.8 Hz sinusoidal modulation, dV/V = 0.250 % p-p gives steady-state mean P_inst = 1.000 |
| 5 | CPF with 4096 log-spaced classes (linear interpolation in a class) over the 10-min window after a 30 s pre-roll; smoothed percentiles and P_st formula as specified; exact percentiles computed as a cross-check (agree within 0.1 %) |
| d(t), d_c, d_max, T_max | half-cycle rms; steady state = every half cycle covered by a >= 1 s window with max-min <= 0.4 % of U_n (+/-0.2 % band); d(t) relative to the preceding steady-state level; d_c = difference of adjacent steady states; T_max = longest run with d > 3.3 % |
| electrical model | ideal 230 V source + Zref = 0.40 + j0.25 ohm, heater 52.9 ohm, triac ideal, fires 230 us after each zero crossing of an 'on' cycle, exact R-L transient; half-cycle rms off 230.00 V, on 228.27 V -> step dV/V = 0.752 % |
| switching pattern | bit-exact model of the ISR: 16-bit accumulator, increment round(pid_output * 65536), one decision per full cycle, accumulator starts at 0, constant duty over 10 min |

Notes: the 8.8 Hz sine is the calibration point (mean = 1 by construction; P_inst,max = 1.031 is the 300 ms-filter ripple, inside +/-8 %). Rectangular points 1...1620 cpm (the band that matters for this appliance) are within +0.1...+2.8 %. 4000 cpm (33.3 Hz) is +2.8...+3.9 % over the carrier phases (inside +/-5 %). 4800 cpm (40 Hz) is +31...+35 % (over carrier phases): the modulation fundamental (40 Hz) is above the 35 Hz low-pass, and 2/3 of the response comes from the 3rd harmonic of the rectangle (120 Hz) mixing with the 100 Hz term of the squared carrier into a 20 Hz component (probe: mean P_inst with the whole rectangle 3.29, fundamental only 1.13, 3rd harmonic only 2.15). That point therefore depends on the exact edge shape / bandwidth of the rectangular test generator and the reference meter, not on the 1...25 Hz path; the dV/V value 4.834 % for 4800 cpm was taken from the brief and could not be checked against the standard here. The carrier-phase sweep (8 phases) changes 4000/4800 cpm results by < 4 %. The heater patterns have no content above 25 Hz (per-cycle switching), so this does not affect the results below. Both HP orders give the same conclusions (differences <= 1.7 %).

Observations (from the table):

- No pattern that switches faster than about once per second passes P_st <= 1.0 at all duties (SD with K <= 25, bursts of 1-2 s, 2nd-order SD at K = 1); SD with K = 2...8 and the 2nd-order SD at K = 1 are even worse than the current firmware: with full-cycle switching the modulation band is only 0...25 Hz, so noise shaping has nowhere to push the energy (the weighting is still 0.25 at 25 Hz), and the 1-bit 2nd-order loop adds limit-cycle tones inside the peak region (duty 0.52: 0.28 % at 10 Hz, 0.22 % at 8 Hz -> P_st 2.41; duty 0.20: 0.29 % at 15 Hz -> 1.26).
- P_st falls with the number of voltage changes per minute. Fixed-period bursts have at most 2 changes per period at every duty, so their worst case is flat over duty; sigma-delta with long K has the same P_st but an irregular pattern, a long slowest power period and a duty error of up to 3 % within 10 min.
- Because the dryer runs for hours, P_lt <= 0.65 is the binding limit at steady duty (P_lt = P_st). The 10 s burst (worst 0.68) meets P_st <= 0.8 but not P_lt; 20 s is the shortest period tested that meets P_lt with margin.

## 5. Recommendation

| | current firmware | recommended |
|---|---|---|
| pattern | 1st-order SD, decision every 1 cycle(s) (20 ms) [current firmware] | burst PWM + error carry, period 1000 cycles (20 s) |
| worst P_st over duty (0.01 grid + listed) | 1.70 (duty 0.80) | 0.54 (duty 0.99) |
| margin to P_st 1.0 / P_lt 0.65 | -70 % / -161 % | +46 % / +17 % |
| d_c / d_max worst | 0.75 % / 0.75 % | 0.75 % / 0.75 % |
| voltage changes per minute (max) | 3000 | 6 |
| duty resolution | 1/65536 | per 20 s frame 1/1000 (0.1 %), long-term mean 1/65536 via the carried remainder |
| chamber ripple pp, tau 60 / 180 / 300 s (% of full-power rise) | 0.03 / 0.01 / 0.01 | 8.5 / 3.0 / 1.9 (e.g. 100 K full-power rise, tau 3 min: 3.0 K pp at duty 0.5) |
| slowest power-modulation period | 2 s | 20 s (fixed) |

Firmware rule (no firmware file was edited):

1. Keep the zero-crossing ISR, the 230 us firing delay, the 150 us gate pulse and firing at both zero crossings of an "on" cycle; keep the existing every-other-zero-crossing decision point.
2. Replace the per-cycle accumulator decision by a 20 s frame: a cycle counter `cyc` (0...999) advances at each decision point. When `cyc == 0`: latch the current `sd_increment`, do `acc += sd_increment * 1000` (uint32; 65536 * 1000 fits), `n_on = acc >> 16`, `acc &= 0xFFFF`. For `cyc < n_on` set `fire_cycle = true`, otherwise false. Each frame is one block of consecutive "on" cycles followed by one block of "off" cycles, i.e. at most 2 voltage changes per 20 s; the carried remainder keeps the long-term mean duty exact.
3. The frame length is a cycle count (1000 cycles = 20 s at 50 Hz); 1500 cycles (30 s, worst P_st 0.47) is the next step if more margin is wanted. Do not shorten below 1000 cycles (500 cycles = 10 s fails P_lt at 0.68).
4. Control side: the actuator now updates every 20 s; the PID can keep running at 4 Hz (only the value latched at frame start is used) but should be retuned for the 20 s sample-and-hold (lower derivative gain / filtered derivative, anti-windup) and the thermocouple reading averaged over the frame so the PID does not chase the 20 s ripple.

## 6. Simplifications and assumptions

| item | simplification |
|---|---|
| limits | P_st 1.0, P_lt 0.65, d_c 3.3 %, d_max 4 %, T_max 500 ms and Zref = 0.40 + j0.25 ohm were taken from the text of IEC 61000-3-3 as quoted in the brief; the only local copy is a 21-page preview without the limits clause, so they were not read from a file |
| flicker test-point values | taken from the brief (IEC 61000-4-15 Table values as quoted); not checked against the standard |
| constant duty | duty constant for the whole 10 min (worst case steady regulation); the real PID changes the increment every 250 ms; P_lt = P_st |
| supply / load | ideal sine source, no background flicker; 10 W auxiliary load ignored; heater resistance independent of temperature; triac ideal (no on-state voltage); current carry-over past the voltage zero (about 15 us) ignored |
| adaptor | first-order 27.3 s mean-square tracker on the sampled waveform (not a half-cycle-rms based adaptor); immaterial for steady 230 V |
| calibration | gain fixed numerically on the steady-state mean of P_inst for the 8.8 Hz / 0.25 % sine (not on P_inst,max) |
| classifier | 4096 log classes over [1e-6 * max, max] of each record (adaptive range instead of a fixed range) |
| d-parameters | half-cycle rms (not 1-cycle rms refreshed every half cycle); steady state detected by a sliding 1 s window with max-min <= 0.4 %; d(t) referenced to the last steady state (2 s of heater-off prepended); no separate "voltage change characteristic" segmentation beyond that |
| thermal | single first-order chamber model; real heater element and sensor ripple will be larger than the chamber-air ripple if the sensor sits close to the element |
| statistics | single 10-min window per duty, pattern started 30 s before the window (sigma-delta accumulator from 0) |
