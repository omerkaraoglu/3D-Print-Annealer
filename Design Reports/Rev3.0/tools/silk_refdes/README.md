# Silkscreen legend and reference designators (Rev3.0 board)

Scripts of the silkscreen / reference-designator round of 2026-11-13 (spec §12.10). They are adapted from the Battery
Sentinel refdes round (`Battery Sentinel/V1.0/Generated by Claude/Layout-Scripts/refdes/`, reviewed 2026-10-15) and its
legend pass (`silk.py`): same obstacle raster, candidate generation, ownership test, optimiser and legend-map rules.

| Script | Python | Does |
|---|---|---|
| `cfg.py` | – | paths (working tree `ROOT`, default the session scratchpad, override with the env var `SILK_ROOT`), raster window, board-only parts (H1–H9, DS1) |
| `labels_def.py` | – | the board legend (functional labels, pin marks, title block, mains warning), the old texts it replaces, the Cmts.User fabrication notes |
| `refdes_geom.py` | KiCad | geometry export: outline, holes, courtyards, mask apertures, library and board silk, F.Cu tracks, Cmts.User mains outline, text ink boxes |
| `silk_labels.py` | system | places the board legend (nearest free spot to each target: pads 0.25, silk / edge / holes 0.5 mm; title and warning also off courtyards and tracks, warning inside the mains outline) |
| `refdes_place.py` | system | designator placement (raster 0.025 mm, mask 0.15, silk 0.15, edge / holes 0.30, ownership test, row consistency, legend maps) |
| `refdes_apply.py` | system | CRLF-preserving text patch of `orig/` (Reference fields, removed old texts, new legend / notes / map graphics, uuid5 uuids) |
| `silk_fix.py` | system | silk-only fixes of footprint instances (U1/U5 outlines off the creepage slot with pin-1 triangles, J20 pin-1 mark off D220) and the Q1/HS1 silk rule in the staged `.kicad_dru` |
| `art/art_gen.py` | system | front artwork: readark logo PNG + Manrope lines traced to polygons (OpenCV), placed by search on the obstacle raster (mask 0.15, silk 0.15, courtyards 0.15, edge 1.0, holes 0.3, antenna keep-out), logo as wide as the free spot allows → `work/art/art.json` (needs opencv-python, fontTools) |
| `art/art_apply.py` | KiCad | removes the four title-block texts, appends the artwork as fractured filled gr_poly on F.SilkS (uuid5) |
| `art/qr_gen.py` | system | QR code to the AnnealX product video (segno, lowest version at level M; light modules + quiet zone printed, dark modules show the mask, R1.8 corners as on Battery Sentinel), 0.5 mm modules, placed by search on the obstacle raster of the real board (`work/geom_now.json` + designator boxes; mask 0.15, silk 0.15, courtyards 0.15, edge 0.5, holes 0.3, antenna keep-out) in the pocket left of J10 → `work/art/qr.json`; `--map` prints the largest free squares (needs segno, opencv-python) |
| `art/qr_apply.py` | KiCad | appends the QR code as fractured filled gr_poly on F.SilkS (uuid5), refuses a board that already has it, writes atomically (temp file + `os.replace`) |
| `art/assets/` | – | `readark-logo-white.png`, `Manrope[wght].ttf` and its `OFL.txt` (SIL Open Font License 1.1), copied from Battery Sentinel's Silkscreen-Art |
| `run_all.py` | system | the whole chain, see below |
| `refdes_check.py` | KiCad | exact polygon check of every designator, map graphic and legend text, ownership, maps as uniform scaled copies, KiCad DRC with check-only silk rules |
| `refdes_diff.py` | system | structural diff orig vs stage: only Reference fields, removed old texts and the new items may differ |
| `refdes_drc.py` | system | project DRC of orig and stage, item by item (`--refill` refills zones; a board path as argument: one DRC) |
| `refdes_render.py` | system | renders (SVG layers via kicad-cli + PyMuPDF): board 20 px/mm, crops 60 px/mm, `--courtyard` adds courtyards |
| `silk.py`, `silk_c23.py` | – | the Battery Sentinel legend scripts, kept for reference only (they need that project's `stage.py` / `boardlib.py`) |

System python needs numpy, scipy, Pillow, matplotlib and PyMuPDF; KiCad python is
`C:\Program Files\KiCad\10.0\bin\python.exe`.

## Rerun recipe

```
# 0. working tree (ROOT): orig/ = the board to start from, never written
#    orig/3dFilamentDryer.kicad_pcb, orig/3dFilamentDryer.kicad_pro (from git HEAD), orig/3dFilamentDryer.kicad_dru
python run_all.py                                   # geom -> legend -> labelled board -> geom -> designators -> stage/ -> silk_fix -> artwork -> QR code
# QR code alone, on a board that has everything else (URL = run_all.VIDEO_URL):
#   "C:\Program Files\KiCad\10.0\bin\python.exe" refdes_geom.py <board> <ROOT>/work/geom_now.json
#   python art/qr_gen.py https://readark.eu/annealx/7j7aux/    (python art/qr_gen.py --map: largest free squares)
#   "C:\Program Files\KiCad\10.0\bin\python.exe" art/qr_apply.py <board> <out board>
"C:\Program Files\KiCad\10.0\bin\python.exe" refdes_check.py    # 0 failures expected
python refdes_diff.py                               # other differences: 0
python refdes_drc.py                                # orig vs stage, item by item
python refdes_render.py <ROOT>/stage/3dFilamentDryer.kicad_pcb <out> "" --regions <ROOT>/work/regions.json --legends <ROOT>/work/placement.json
# then copy stage/3dFilamentDryer.kicad_pcb and stage/3dFilamentDryer.kicad_dru over the project files (KiCad closed),
# check md5 and DRC there
```

Candidate generation (about 80 s) is cached in `work/cands_cache.pkl`, keyed on the geometry, the parameters and the code.
Each run from the same `orig/` gives the same file (uuids are uuid5 of item names).

## Notes

- A polygon with holes (a library silk outline exported as a ring) used to be drawn straight into the obstacle raster,
  and its hole erased what was drawn before it (here: J20's inner body line). `Grid.fill` now draws such polygons on
  their own patch. The Battery Sentinel scripts have the old version.
- kicad-cli 10 PDF export draws stroke text about 3 % wider than the board geometry (Gerber and SVG agree with the
  geometry), so the renderer plots SVG; F.Fab stays PDF for its `--exclude-refdes` option.
- `OWN_EXEMPT`: Q1 sits on the HS1 heatsink plate (courtyard inside the heatsink's), so HS1 is not an "other part" for
  Q1's label (refdes_place.py and refdes_check.py).
- The open KiCad session rewrites `3dFilamentDryer.kicad_pro` with stale net classes when the board file changes
  under it (seen twice on 2026-11-13); with that file DRC reports hundreds of clearance errors. Restore it from git
  HEAD (`git show HEAD:KiCad/3dFilamentDryer/3dFilamentDryer.kicad_pro > ...`) before running DRC, and close or
  reload KiCad before saving anything.
